# API de Administración del Sistema | Proyecto: BiblioConnect

Este repositorio aloja la implementación de la API dedicada a las **funcionalidades de administración y gestión** del Sistema de Gestión Bibliotecaria **BiblioConnect**.

Esta API proporciona endpoints seguros para realizar **tareas a nivel de sistema**, tales como:

- Gestión de usuarios con roles administrativos y permisos.
- Configuración global del sistema.
- Generación de reportes administrativos y estadísticas.
- Monitoreo y acceso a registros (logs) del sistema (opcional).
- Tareas de mantenimiento y utilidades administrativas.

Este servicio está diseñado para ser utilizado por el panel de administración o herramientas internas y no está destinado a ser accedido por usuarios regulares.
